# taktekbot/merch

The merch shop at https://taktekbot.com/merch/: every piece has to be won before it can be bought.
Built with [earned](https://github.com/taktekhq/earned): `store.json` + one game per piece in `games/`,
`node ../earned/build.mjs .` writes the pages. `print/` holds the Printful print files,
generated by taktekhq/brand (build/collection02_art.py).
